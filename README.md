# 노래책

인터넷 방송인용 노래 목록 사이트. 서버 없이 정적 파일만으로 동작합니다.

## 파일 구성

- `index.html`, `script.js` — 시청자가 보는 목록 페이지에 곡 추가/삭제·상세 편집 기능까지 한 파일에 들어있습니다 (더 이상 별도의 admin 페이지나 비밀번호 화면이 없습니다).
- `songs.json` — 실제 사이트에 표시되는 곡 목록 데이터
- `style.css` — 공통 스타일

## 로컬에서 미리보기

`songs.json`을 `fetch`로 불러오기 때문에 파일을 더블클릭해서 열면(file://) 브라우저 보안 정책으로 목록이 안 보일 수 있습니다. 로컬 서버로 열어주세요.

```
npx serve .
```

또는

```
python -m http.server 8000
```

## GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 Settings → Pages → Source에서 배포할 브랜치(예: main)와 루트 폴더(`/`)를 선택합니다.
3. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/`에서 사이트가 열립니다.

## 곡 추가/수정하기

화면 전환이나 비밀번호 없이, 노래책 목록 페이지 그대로에서 곡을 추가/삭제합니다.

- 화면 우측 상단의 **"+" 버튼**을 누르면 곡 추가 팝업이 뜨고, 저장하면 바로 GitHub에 반영되고 목록에도 즉시 보입니다.
- 목록의 각 곡 오른쪽 **🗑️ 삭제 아이콘**을 누르면 확인 후 바로 GitHub에서 삭제됩니다. 곡을 클릭하면 수정 팝업이 뜹니다.
- 페이지 아래쪽 **"관리자 도구"** 접이식 섹션에서 태그·비고·숙련도 수정, GitHub 연동 설정, 엑셀 불러오기, 일괄 선택/삭제, JSON 내보내기/불러오기 등 더 상세한 기능을 쓸 수 있습니다.

**주의:** 이 버튼들은 누구나 볼 수 있고 누를 수 있습니다. 다만 실제로 GitHub에 곡을 추가/삭제하려면 아래 "GitHub 연동 설정"에서 저장한 **쓰기 권한 토큰이 그 사람의 브라우저에 저장되어 있어야만** 동작합니다 — 토큰은 다른 사람에게 공유되지 않고 방송인 본인 브라우저에만 남아있으므로, 시청자가 버튼을 눌러도 "GitHub 연동이 설정되어 있지 않습니다" 오류만 뜨고 실제로는 아무 일도 일어나지 않습니다. **토큰을 아는 사람에게 노출되지 않도록만 주의해주세요.**

### GitHub 연동 설정 (한 번만 하면 됨)

곡을 저장하면 바로 사이트에 반영되도록, GitHub 저장소에 쓰기 권한이 있는 토큰을 발급받아 연결합니다. **이 설정을 먼저 해둬야 "+" 추가 버튼과 🗑️ 삭제 아이콘이 동작합니다.**

1. GitHub에서 [Fine-grained personal access token 발급 페이지](https://github.com/settings/personal-access-tokens/new)로 이동합니다.
2. **Repository access**에서 "Only select repositories"를 고르고 이 노래책 저장소만 선택합니다.
3. **Permissions → Repository permissions → Contents**를 "Read and write"로 설정합니다. (다른 권한은 필요 없습니다)
4. 토큰을 생성하고 복사해둡니다. (이 화면을 벗어나면 다시 볼 수 없으니 꼭 복사)
5. "관리자 도구"를 펼치고 그 안의 "GitHub 연동 설정"을 펼쳐서 계정명, 저장소 이름, 브랜치(기본 `main`), 토큰을 입력하고 "설정 저장"을 누릅니다.
   - 이 정보는 지금 사용 중인 브라우저에만 저장됩니다. 토큰은 곧 이 사이트의 저장소를 수정할 수 있는 비밀번호와 같으니, 공용 컴퓨터에서는 입력하지 마세요.

### 곡 자세히 편집하기 (관리자 도구)

"관리자 도구"를 펼치면 태그·비고·숙련도를 곡마다 직접 수정할 수 있는 표가 나옵니다.

1. 곡을 수정/삭제합니다. 편집 내용은 편집하는 즉시 메모리에만 반영되고, 페이지를 새로고침하면 사라집니다 — 아직 **GitHub에는 저장되지 않은 상태**입니다.
   - **태그**(한식, 일식, 양식)는 선택 버튼을 눌러 켜고 끕니다. 여러 개를 동시에 켤 수 있습니다.
   - **비고**는 자유롭게 텍스트를 입력하는 칸입니다. 쉼표(,)로 구분하면 여러 개를 넣을 수 있습니다. (예: "완숙, 관상용")
   - 태그 종류를 바꾸고 싶으면 `script.js`의 `TAG_OPTIONS` 배열을 수정하면 됩니다.
2. 다 편집했으면 **"GitHub에 저장"** 버튼을 누르면 곧바로 저장소의 `songs.json`이 갱신되고, 잠시 후 실제 사이트(목록)에도 반영됩니다.

GitHub 연동을 설정하지 않았거나 다른 컴퓨터에서 파일로 옮기고 싶다면, **"JSON 내보내기"**로 파일을 받아 저장소의 `songs.json`을 직접 덮어써서 커밋/푸시해도 됩니다. **"JSON 불러오기"**로는 그 파일을 다시 불러와 이어서 편집할 수 있습니다.

### 엑셀로 곡 한꺼번에 추가하기

**"엑셀로 곡 추가"** 버튼으로 `.xlsx` 파일을 올리면, 모든 시트를 훑어서 곡을 기존 목록에 추가합니다.

- **"양식" 시트**는 C열 2행부터 가수, D열 2행부터 제목, E열 2행부터 비고를 읽습니다.
- **"한식", "일식" 시트**는 한 칸씩 왼쪽으로 밀려서 B열 2행부터 가수, C열 2행부터 제목, D열 2행부터 비고를 읽습니다. (실제 스프레드시트 구조가 그렇게 되어 있어서 `script.js`의 `shifted` 판정에서 시트 이름으로 구분합니다)
- 두 경우 다 1행은 머리글로 보고 건너뜁니다. 다른 이름의 시트를 추가하면 기본적으로 "양식"과 같은 C/D/E 배치로 읽으니, 시트가 B/C/D 배치라면 `script.js`의 `shifted` 판정 조건에 그 시트 이름을 추가해야 합니다.
- 시트 이름이 그 시트에 있는 곡들의 **태그**로 자동 입력됩니다. (예: "한식" 시트의 곡은 태그가 "한식") E열 값이 있으면 **비고**로 같이 들어갑니다. (비고는 자유 입력이라 어떤 값이든 그대로 들어갑니다)
- 시트 이름이 위 태그 종류 목록에 없으면 데이터에는 저장되지만 화면의 선택 버튼으로는 표시되지 않습니다.
- 가수나 제목 중 하나라도 비어 있는 줄은 건너뜁니다.
- 기존 목록은 지워지지 않고, 새로 읽은 곡이 뒤에 추가됩니다. 중복 여부는 확인하지 않으니, 같은 파일을 두 번 올리면 곡이 중복됩니다.
- 난이도는 별도 입력이 없어 0으로 들어가며, 필요하면 추가 후 별점으로 직접 조정하면 됩니다.
